# 🌤 Weather App

A simple weather application built using HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Shows temperature
- Shows humidity
- Shows wind speed
- Displays weather condition
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeather API

## How to Run
1. Download the project.
2. Open the folder in VS Code.
3. Replace the API key in `script.js` with your own OpenWeather API key.
4. Open `index.html` using Live Server.
